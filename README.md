# Obsidian Productivity Bot Data

Этот репозиторий хранит Markdown-файлы, которые Telegram-бот продуктивности синхронизирует с Obsidian.

## Файлы

- `план-факт продуктивности.md` - ежедневная таблица план-факт.
- `отчеты продуктивности.md` - недельные и ручные отчеты.

## Важно

В репозитории не должно быть:

- Telegram-токенов.
- `.env`.
- `state.json`.
- личных ключей сервера.

Бот на сервере пишет сюда Markdown-файлы, сервер делает `git commit` и `git push`, а Mac/Obsidian подтягивает изменения.
